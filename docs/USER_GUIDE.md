# 한빛유통 회계 자동화 학습 안내

회계 자동화 기술과 회계의 흐름을 공부하고 싶은 사람을 위한 공간입니다. 코딩을 몰라도 가상 거래를 가지고 분개·검사·직접 승인·장부 반영·보고서 확인까지 연습할 수 있습니다.

1. [처음 시작하기](GETTING_STARTED.md)의 GitHub 주소가 포함된 요청문 하나를 코덱스 또는 클로드 코드에 보냅니다.
2. AI가 안내하면 학습 폴더를 열고, 본인 Google 로그인과 앱 연결을 직접 허용합니다.
3. [전체 학습 순서](WORKFLOW_GUIDE.md)의 첫 매출 한 건 요청문으로 연습합니다.
4. 사이트에서 직접 승인한 뒤 AI에게 장부 반영을 요청합니다.
5. 해당 월의 시산표와 재무제표에서 숫자가 어떻게 이어졌는지 확인합니다.

[사이트 열기](https://ledgerflow-public-reference-gateway.eric5833.workers.dev/) · [시작 요청문](GETTING_STARTED.md) · [예제로 보는 전체 흐름](WORKFLOW_GUIDE.md)

API 키나 DB를 직접 준비하지 않습니다. 거래 1,000건은 연습 자료이며, 개인 장부에서 장부 반영까지 마친 전표만 보고서에 집계됩니다. 외부 공시·법령·금리 자료는 가상회사 거래와 구분되는 참고 근거입니다. 실제 조회 여부는 개별 출처 표시로 확인하세요.

현재 제공 기능과 실제 검증 범위는 [구현·검증 기록](IMPLEMENTATION_STATUS.md)에 정리했습니다. 예전 DB 접속 실패나 샘플 모드를 현재 상태로 오해하지 않도록 첫 사용 안내를 위 문서로 통일합니다.
