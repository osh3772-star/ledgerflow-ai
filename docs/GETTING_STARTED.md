# 처음 시작하기 — GitHub 주소와 요청문 하나

회계 자동화 기술과 회계의 흐름을 공부하고 싶은 사람을 위한 학습 공간입니다. 코딩을 몰라도 가상 한국 도소매 회사 **한빛유통**의 자료로 거래 → 분개 → 검증 → 직접 승인 → 장부 반영 → 재무제표를 따라갈 수 있습니다.

[사이트 열기](https://ledgerflow-public-reference-gateway.eric5833.workers.dev/) · [GitHub 저장소](https://github.com/osh3772-star/ledgerflow-ai)

## 시작 요청문을 한 번 보내세요

1. 파일과 앱 설정을 다룰 수 있는 **Codex · 코덱스**, **Claude Code · 클로드 코드**, **Antigravity · 안티그래비티** 중 현재 앱을 엽니다. 본인의 앱 계정과 Node 24 런타임이 필요합니다.
2. 아래 요청문을 **AI 대화창에 한 번** 붙여 넣습니다. GitHub 주소도 포함돼 있습니다.
3. AI가 현재 폴더에서 역할 파일과 연결 설정을 준비하고 내 임시 장부를 발급받아 두 회계 도구를 호출합니다. 연습 시작에 Google 로그인이나 폴더 이동은 필요 없습니다.

```text
나는 코딩을 모르고 회계 자동화와 거래가 장부·재무제표로 이어지는 흐름을 배우고 싶어.
https://github.com/osh3772-star/ledgerflow-ai
이 저장소의 docs/START_HERE.md를 읽고 지금 사용하는 Codex·Claude Code·Antigravity 중 현재 앱에 바로 설정해 줘.
현재 열린 폴더를 바꾸지 말고 기존 파일을 보존하면서 6개 역할 지침과 활성 MCP 연결 하나를 병합해 줘. 공유 서버에서 내 임시 학습 장부를 자동 발급받고 접속 키는 비공개 설정에만 저장해. 서버·DB·API 키는 새로 만들지 마. Google 로그인은 연습 시작에 필요 없어.
설치 스크립트의 실제 MCP 호출 검사까지 실행한 뒤 현재 앱에서도 get_system_status → get_company_context를 호출해. 프로토콜 검사 성공과 현재 앱 도구 호출 성공은 구분해서 알려줘. 앱이 새 연결을 읽지 못하면 가능한 갱신을 시도하되 신뢰·보안 확인을 우회하거나 연결 성공을 꾸미지 마.
내 연습 회사와 첫 매출 한 건을 공부하는 요청문을 보여줘. 아직 분개 생성·승인·장부 반영은 하지 마.
```

회계 서버·데이터베이스·공공 API 키를 직접 설치하거나 발급받지 않습니다. AI가 현재 폴더에서 임시 장부 키와 현재 앱의 연결 설정을 준비합니다. 임시 장부는 24시간 동안 접근할 수 있고, 보관하려는 경우에만 Google을 연결합니다. AI 앱 자체의 신뢰 확인·새 연결 읽기는 앱 정책에 따라 필요할 수 있으므로 모든 앱·버전의 무클릭 완료를 보장하지 않습니다.

## 어디까지 끝났는지 이렇게 확인하세요

| AI가 알려주는 상태 | 의미 | 다음에 할 일 |
| --- | --- | --- |
| 설정 준비됨 | 현재 폴더와 현재 앱의 연결 설정이 병합됨 | AI가 실제 연결 검사를 계속 진행 |
| MCP 통신 검사 성공 | 설치 스크립트가 실제 status/context를 호출함 | 현재 앱에 도구가 표시되는지도 AI가 확인 |
| 현재 앱 연결 확인됨 | 현재 앱의 두 도구 호출이 실제 성공 | 첫 거래 한 건으로 학습 시작 |
| 앱 새 연결 읽기 대기 | 앱이 실행 중 설정 변경을 읽지 못함 | 앱 고유 새로고침·신뢰 확인이 필요한 경우만 안내받기 |

‘설치했다’는 설명이나 파일 목록만으로 연결이 끝났다고 판단하지 마세요. 설정 병합·MCP 통신 검사·현재 앱 도구 호출은 서로 다른 단계입니다. 현재 앱이 실행 중 새 도구를 표시하지 못하면 필요한 연결 갱신만 안내받습니다. Google 로그인은 임시 연습에 필요 없습니다.

## 연결됐다면 첫 거래를 공부하세요

1. **AI 대화창:** 첫 거래 요청문을 보냅니다. 거래 설명·분개 초안·오류 검사 결과와 승인 링크를 받습니다.
2. **승인 링크:** 내가 직접 열어 거래일·계정·금액·증빙을 확인하고 승인 또는 반려 버튼을 누릅니다. 로그인 없이 전표에 묶인 학습용 승인 화면이 열립니다. 링크를 공유하거나 AI에게 대신 승인하게 하지 마세요.
3. **AI 대화창:** 승인 후 장부 반영 요청문을 보냅니다.
4. **승인 화면의 장부 보기 링크:** 사이트를 새로고침 → 2026년 1월 → 재무 보고서에서 바뀐 숫자를 확인합니다.

요청문과 예제는 [전체 학습 순서](WORKFLOW_GUIDE.md)에 있습니다. 한 건을 이해한 뒤 한 달 정리·결산·감사 점검으로 넓혀보세요.
