# LedgerFlow

Follow the shared project rules in @AGENTS.md and role contracts in
@docs/CLIENT_ROLES.md. Native roles are in `.claude/agents` and their skills in
`.claude/skills`. The root `.mcp.json` defines the only MCP server.
For the disposable local demo, run `pnpm start` once in a separate terminal
before opening this project. Keep that terminal open; do not start another
server for each app. First-time recipients should follow @docs/GETTING_STARTED.md.
See @docs/CLIENT_SETUP.md for persistent DB connections and verification.
